Knowledge check: Sharing information in Power BI
    1. Question 1
    What is the purpose of Row-level security (RLS) in Power BI?
    => To display only the data rows that a user's identity or role permits

    2. Question 2
    Which security measure in Power BI allows users to work with obscured versions of sensitive data?
    => Data masking

    3. Question 3
    What is the primary purpose of the People with Existing Access sharing option in Power BI?
    => To limit viewership to those previously granted permission

    4.Question 4
