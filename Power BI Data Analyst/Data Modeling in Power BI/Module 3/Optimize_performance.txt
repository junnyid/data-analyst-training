What are aggregations and why use them?
    - aggregations refer to the process of summarizing data at a higher level, typically to reduce the number of rows and improve performance. 
    - Aggregation is commonly used to pre-calculate totals, averages, counts, and other summary statistics at a more granular level (e.g., monthly totals, yearly totals, etc.)
    - Aggregations are particularly useful in models where the fact tables contain millions or billions of rows, as summarizing the data at a higher level can significantly improve query performance.
    - How Aggregations Work in Power BI:
        + Types of Aggregations in Power BI: Simple Aggregations; Custom Aggregations
        + Improved Query Performance
        + Reducing Memory Usage
        + Faster Data Refreshes
        + Enhanced User Experience
        + Reducing Query Load on Data Source
