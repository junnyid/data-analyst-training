Knowledge check: Designing an Accessible Report
    1. Question 1
    Which issues can you address by implementing accessibility features and practices in Microsoft Power BI reports? Select all that apply. 
    => Ensuring visually impaired users can understand report visuals.
    => Making the report easily understandable to people who use assistive technologies for navigation.
    => Helping people with cognitive disabilities understand the report easily.

    2. Question 2
    A data analyst in your organization cannot use a mouse due to a recent injury. Which feature should you implement in your Microsoft Power BI reports to assist her in navigating and interacting with them?
    => Tab order

    3. Question 3
    Some of the executives in a recent meeting have complained about feeling overwhelmed by the multitude of visuals on your Microsoft Power BI reports. Which feature should you utilize in Power BI to improve their user experience?
    => Focus mode

    4. Question 4
    One of your team members has low vision and relies on a screen reader to understand the contents of a Microsoft Power BI report. He said it was difficult to distinguish between different elements in the report, and the screen reader did not provide enough context for visuals. Which features should you utilize to improve his experience with your Power BI reports? Select all that apply.
    => All Text
    => High-contrast colors

    5. Question 5
    Your organization has committed to ensuring all Microsoft Power BI reports are accessible. You have implemented several measures, including adding alt text to all visuals and enabling keyboard navigation. However, feedback from a color-blind user indicates that they're having difficulty interpreting some visuals due to their color usage. Which of the following steps would be most appropriate to improve accessibility for color-blind users further?
    => Use high-contrast colors, shaded colors, or pattern fills


Knowledge check: Report Navigation and Filtering
    1. Question 1
    You have two visuals on a business intelligence dashboard: one shows sales by region, and the other shows sales by product. When you select "North" in the regional visual, the product visual updates to show only products sold in that region. What is this interaction called?
    => Cross-filtering

    2. Question 2
    You're viewing a dashboard with two visuals: one shows monthly sales by region, and the other is a stacked column chart showing monthly order quantity by status. When you select June in the "West" region on the first visual, certain sections of the June column in the second chart become highlighted, while the rest fade. What is this interaction called? 
    => Cross-highlighting

    3. Question 3
    You're building a dashboard that summarizes total sales across all retail stores. When a user selects "California," you want to direct them to a new report page with detailed sales data for each store in that state. Which feature enables this interaction? 
    => Drillthrough

    4. Question 4
    You are reviewing monthly sales data for the year but want to focus only on July, August, and September. Which feature allows you to limit the display to just these months?
    => Filtering

    5. Question 5
    You have data about employee turnover across departments and regions. To analyze it effectively, you want to order the fields from the most general to the most specific. Which option shows the correct hierarchy? 
    => Department, Region, Team, Turnover Rate
