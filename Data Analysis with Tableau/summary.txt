Data Analysis Process Overview

Prepare Data => Analyze Data => Develop Insights => Build Story

    1. Data Preparation
        Exploration & Preprocessing
        - The data preparation stage focusses on understanding raw data and transforming it into a format that's optimized for analysis.
        - These tasks:
            + Adjusting data types
            + Combining tables
            + Identifying relationships between fields
            + Creating calculated fields
            + Adding filters
            + Reshaping data

    2. Data Analysis
        Visualizations & Statistics
        - There are 03 main steps:
            + Creating visualizations
            + Calculating Statistics
            + Identifying patterns

    3. Insight Development
        come from observations & identified patterns - actionable trends & patterns
        - Ask yourself questions:
            + What are the key takeaways from the data or information?
            + How does this information provide a new perspective or understanding?
            + How does this help me solve the business problem or challenge?

    4. Data Storytelling
        resonates with audience - may need worksheets or dashboards - provides context & interpretation
        - A Tableau story involves arranging worksheets or dashboards into a sequence similar to a slide deck
        - understanding of the data's implications, a clear vision of the key messages 
        - build worksheets or dashboards to successfully convey your narrative


Data Exploration
    - data exploration is about asking the right questions, while preprocessing is about taking the right actions in response to those questions.
    1. Exploring Structure and Metadata
        - The structure refers to the physical layout of your data — how it's organized in terms of rows and columns
        - Metadata, on the other hand, is the information about the data within your dataset, such as field names and data types.
        - Preparing the structure and metadata of a dataset generally involves three tasks: 
            + Determining structure
            + Renaming fields
            + Editing field data types
    
    2. Relationships, Joins, and Unions
        - Combining data from multiple tables is often necessary to create a comprehensive view of datasets
        - Tableau can combine tables in the following ways:
            + Relationships
            + Joins
            + Unions
            + Cross-database Joins
            + Data blends
    
    3. Organizing and Customizing fields
        - Tableau provides various methods to restructure and combine fields. 
        - A key question to guide your exploration "Could the fields be restructured for better organization, navigation, or analysis?"
        - Combine fields in the following ways:
            + Folders
            + Hierarchies
            + Pivot fields
    
    4. Combining Values
        - involves consolidating individual data points within a field into more meaningful categories or groups
        - a guiding question here is: "Within a single field, are there values that can be categorized under a single value?"
        - Values can be combined in the following ways:
            + Groups 
                Groups essentially build a new field based on the original field chosen, but the values are now grouped with their respective "group names."
            + Sets 
                Sets function similarly to groups, as they allow you to segment a portion of your values in a new field
                Sets, on the other hand, split up all the values into two groups — in or out of the set.
                The in/out modes of sets in Tableau offer a dynamic way to control which data points are included or excluded from your visualizations.
    
    5. Removing Fields and Values
        - Removing fields and values is crucial for focusing your analysis on relevent data. 
        - These steps allow you to exclude irrelevant or undesired values and fields. 
        - Methods:
            + Hiding fields 
            + Adding filters
    
    6. Creating Fields 
        - Creating fields in Tableau is a key step that adds more detail to your dataset, different from the earlier steps which focus more on organizing and simplifying data.
        - Methods:
            + Creating calculated fields
            + Splitting fields: SPLIT(string, delimiter, token number)
